# 🏆 Aitana Bonmatí – Data-Driven Golden Ball Analysis (FIFA Women’s World Cup 2023)

This repository contains the complete codebase and analysis behind my Medium article:

**“Why Aitana Bonmatí Deserved the Golden Ball — A Data Science Breakdown”**

## 📊 Project Highlights
- ✅ Touch heatmap & pass network
- ✅ Key passes, penalty box entries, progressive flows
- ✅ Custom xT and xG models (built with scikit-learn)
- ✅ xGChain & xGBuildup flow analysis
- ✅ Defensive actions & pressure heatmap
- ✅ Visualizations using `mplsoccer`, `matplotlib`, `pandas`, and `networkx`

## 🧠 Tech Stack
- Python
- Google Colab
- StatsBomb open event data
- `statsbombpy`, `mplsoccer`, `scikit-learn`, `matplotlib`, `seaborn`, `networkx`
