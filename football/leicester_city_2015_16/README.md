# Leicester City — Premier League 2015/16 (The 5000-to-1 Miracle)

A deep dive into Leicester City's historic 2015/16 Premier League season — how a team given 5000/1 odds defied all expectations and became champions of England.

## Notebook

`season_analysis.ipynb`

## Key Analyses

- Season summary and team statistics
- Tactical formation analysis
- Possession and pitch territory trends
- Shot maps, goal locations, and xG analysis
- Player performance breakdowns (Jamie Vardy, Riyad Mahrez, N'Golo Kante, Kasper Schmeichel)
- Build-up sequences leading to goals

## Data

StatsBomb event data fetched at runtime via `statsbombpy`.

## Tech Stack

- Python, pandas, numpy
- statsbombpy (StatsBomb open data)
- matplotlib, seaborn, mplsoccer, plotly
