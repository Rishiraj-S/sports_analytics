# Bayer Leverkusen — Bundesliga 2023/24 (Unbeaten Title Season)

Analysis of Bayer 04 Leverkusen's historic unbeaten Bundesliga title-winning campaign under Xabi Alonso.

## Notebook

`season_analysis.ipynb`

## Key Analyses

1. **Basic Stats Overview** — wins, draws, clean sheets, goal difference
2. **Tactical Formations** — formation flexibility (3-4-2-1, 4-4-2, 4-2-3-1)
3. **Build-Up Play & Passing Networks** — defensive build-up, midfield orchestration, attacking transitions
4. **Shot & Goal Analysis** — shot locations, top scorers, key pass creators, dribble stats
5. **Late-Game Mentality** — goals after the 75th minute and formation shifts

## Data

StatsBomb event data fetched at runtime via `statsbombpy`.

## Tech Stack

- Python, pandas, numpy
- statsbombpy (StatsBomb open data)
- mplsoccer, matplotlib, seaborn
- Jupyter Notebooks
